# Contributing to LeanIQA

## AI Agent Guidelines

When working on this repository, please observe the following rules:

1. **Delete One-Off Scripts**: If you create a one-off debugging script, python script, or data-patch script (e.g. `fix_*.py`, `patch_*.ts`, `test_*.js`, `result.md`, etc.), **delete it immediately after use**. Do not commit these files to the repository. They clutter the root directory and confuse future sessions.
2. **Keep the Root Clean**: The root directory should only contain essential project files (`package.json`, configuration files, core app directories).
3. **No Unused Code**: If you write temporary code, ensure it is removed before concluding your task.
